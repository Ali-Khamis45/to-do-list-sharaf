## Goal
Add PATCH for proposal items with revisions, and the all-or-nothing apply transaction.
Apply locks the conversation, follows the retry rule, and writes the templated acknowledgement.

## Tasks
- [ ] `internal/app/proposals.Apply` locks the conversation, loads the items, and checks owner, status, revision and lifecycle for all of them
- [ ] On any failure it returns 409 with item-level conflicts. Otherwise it commits through Codex's `tasks` service functions, then events, item statuses, and the `template_ack` message.
- [ ] Retry rule: if every item is already in the requested state, return the stored outcome with 200
- [ ] `PATCH /proposal-items/{id}` with `revision` bumps the revision, or returns 409 `stale_revision`
- [ ] Handlers
