Build `GET /days/{date}` with workload and the carry-over count, plus the range query.
Add batch move-unfinished, using the logical day.

## Tasks
- [ ] `GET /days/{date}`: tasks ordered by priority and sort_order, `plannedMinutes`, capacity, and a status of `ok` or `over`
- [ ] Carry-over count from the previous logical day (`internal/domain/civil`)
- [ ] `GET /tasks?from&to&status&later`
- [ ] `POST /tasks/move-unfinished` runs in one transaction, writes events and increments `defer_count`
