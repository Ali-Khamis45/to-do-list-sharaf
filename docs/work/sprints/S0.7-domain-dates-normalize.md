## Goal
Write a pure Go date resolver with the 04:00 logical day and an Arabic normalizer with an offset map.
Add the server templates: tray summary, night date line, acknowledgement, and analysis failure.

## Tasks
- [ ] `internal/domain/civil` holds the Date type and the logical-today calculation with the day boundary
- [ ] `internal/domain/dates` holds the DateExpr types and `Resolve(expr, clock, settings)`, which returns a date, Later, or a clarification
- [ ] The resolver table test has at least 50 rows: 00:45 and 04:10 boundaries, weekday this/next/nearest, Thursday said on a Thursday, year wrap, Egypt DST transitions (embedded `time/tzdata`), and absolute dates without a year
- [ ] `internal/domain/normalize` implements the §7.7 rules and returns the offset map and digit tokens
- [ ] `internal/domain/templates` produces the summary ("اقترحتلك ٤ حاجات، راجعها وأكد"), the night line ("بكرة = التلات 24 نوفمبر"), the ack ("تمام، ضفت ٤ حاجات لبكرة (التلات 24 نوفمبر)."), and the failure text. It includes Egyptian weekday and month names.
