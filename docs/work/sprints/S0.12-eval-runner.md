## Goal
One command runs the golden set through the analyzer and validator, from text or from STT transcript files.
It writes §12.2 metrics per split, and downstream F1 per STT provider.

## Tasks
- [ ] `cmd/eval` and `internal/eval/{match,metrics,report}`: one-to-one matching of expected and actual ops, by keywords first with a flagged LLM-judge fallback. Every §12.2 metric per split, the overclaiming-reply check, latency and cost.
- [ ] Modes: `--input=text` and `--input=stt:<provider>`. The second reads `eval/stt/transcripts/<provider>.json`.
- [ ] Write `eval/reports/<timestamp>.md`. Dev gets per-case diffs. Held-out gets metrics and per-case pass/fail only. Raw model outputs are saved for dev cases only, in `eval/reports/raw/` (local).
- [ ] The Scorer uses Compose Postgres through DATABASE_URL
- [ ] Add `make eval` and `make eval-stt` to `mk/ai.mk`
