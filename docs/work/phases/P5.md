# P5: Hardening-lite & daily use

Effort: ~27 h + 2 weeks of nightly use (hours are the estimate; we plan by scope, not dates)

## Goal
Make the MVP safe to live with: retention purge, verified deletion, cost visibility, error states, deployment, and a backup restore drill.
Then use it every night for 2 weeks and feed every failure back into the golden set.

## Scope
- Retention and orphan purge job, deletion verification, cost and latency report
- Error-state polish
- Production host, secrets, alerts, deploy, restore drill
- Deployed scenario pass and live eval
- 2 weeks of nightly use, failure log, held-out refresh
- Fold failures into dev cases, daily-use metrics, MVP exit decision

## Out of scope
- Everything on the V1 hardening list (roadmap-and-testing.md §13.1)
- V1 features
