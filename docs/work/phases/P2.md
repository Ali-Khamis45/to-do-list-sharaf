# P2: Conversation + AI pipeline in API

Effort: ~40 h (hours are the estimate; we plan by scope, not dates)

## Goal
Serve the full text turn over HTTP. Context comes from the DB, the analyzer runs, deterministic validation follows, and the tray is persisted atomically with server templates.
Apply is all-or-nothing and safe against message edits. Conversation deletion cascades.

## Scope
- AI paths in OpenAPI
- AI store queries and the conversation lock
- AnalyzeTurn use case with reason codes, evidence offsets, and templates
- Conversation and message endpoints with clientMessageId idempotency
- Tray PATCH with revisions, all-or-nothing apply, templated acknowledgement
- Message edit with supersede, retry-analysis, the S31 race test
- Conversation delete cascade, the scenario API suite, and replay analyzer mode

## Out of scope
- Transcription endpoint (P3)
- Frontend (P4)
- Purge job (P5)
