# P1: Go backend foundation

Effort: ~46 h (hours are the estimate; we plan by scope, not dates)

## Goal
Give every later sprint a working Go service to build on. That means a repo skeleton, the full §8 schema, sessions for the 2 seeded accounts, and the task API.
It also includes a spec-first OpenAPI contract with generated clients, verified against the managed Postgres we will deploy on.

## Scope
- Repo skeleton, Makefile, Compose, CI
- goose migrations for all of §8, plus sqlc
- HTTP foundation: router, Problem Details, slog redaction, CSRF, rate limits
- Seeded accounts, scs sessions, settings, delete-my-data
- Task CRUD, lifecycle, events, days/workload, move-unfinished
- OpenAPI root, shell paths, oapi-codegen types, TS types
- Managed Postgres provisioning and target-DB verification

## Out of scope
- Conversation, analysis, and apply endpoints (P2)
- Transcription endpoint (P3)
- Web app (P3/P4)
- V1 hardening items (registration, If-Match, idempotency table, OpenTelemetry)

## Exit gate
Copied exactly from [roadmap-and-testing.md](../../roadmap-and-testing.md) §14 (P1 acceptance):

- Isolation tests pass.
- Concurrent `POST /tasks` with the same id produces one row.
- Lifecycle rules hold.
- Deleting a task removes its events.
- **The §7.5.1 fixture passes against the managed Postgres we'll deploy on.** This includes the Arabic trigram check.
- `docker compose up` gives a working local stack.
