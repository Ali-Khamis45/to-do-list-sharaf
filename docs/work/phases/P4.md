# P4: Frontend app

Effort: ~57 h (hours are the estimate; we plan by scope, not dates)

## Goal
Make journeys J1–J6 work on our phones: the Day view, the Talk sheet with the Plan Tray and safe apply, and Settings & Privacy.
Ship it as an installable PWA shell, with RTL-correct mixed-script text and an E2E suite.

## Scope
- App shell, login, themes, Arabic fonts, dir=auto conventions
- Day view with optimistic toggles, edit, manual add, workload, carry-over
- Talk sheet: thread, composer, recorder integration, transcript edit
- Plan Tray: summary, rows, revisions, 409 handling, ack, night line
- Settings & Privacy, PWA service worker
- Playwright E2E and accessibility basics
- Journey walkthrough on our phones

## Out of scope
- Arabic UI chrome (V1)
- Offline editing (V1)
- Formal WCAG audit (V1 hardening)
