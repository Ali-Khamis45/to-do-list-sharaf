## Goal
Build the Today/Tomorrow/date-picker Day view: task rows, optimistic checkbox, edit sheet, manual add, reschedule and delete.
Add the workload bar and the carry-over banner.

- [ ] Edit sheet. Manual add with a client UUID. Reschedule chips. Delete.
