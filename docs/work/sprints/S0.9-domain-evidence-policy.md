## Goal
Locate evidence on the server and store offsets. Decide numbersMatch and dedupe from supplied scores, and run the re-proposal guard.
Implement the policy table and the full validation pipeline as a pure function.

## Tasks
- [ ] `internal/domain/evidence`: `Locate(quote, U-0..U-2)` tries an exact substring on normalized text first, then an approximate substring (Sellers edit distance) with ratio ≥ 0.8. It maps the match back to code-point offsets, or returns `evidence_not_found`.
- [ ] `internal/domain/dedupe`: numbersMatch, dateCompatible, and `IsDuplicate(score, …)` with a `Scorer` interface whose scores come from the store
- [ ] Re-proposal guard: a create whose evidence is only in U-1/U-2 is checked against every item from those messages, including rejected and withdrawn ones (title-only rule). A match returns `reproposal_of_earlier_item`.
- [ ] `internal/domain/policy`: preselected, maybe, change, or hidden by clarification, plus the low-confidence flag
- [ ] `internal/domain/validate` orchestrates steps 1–9 over a pure input struct. It returns tray items, reason codes, the summary and night lines.
