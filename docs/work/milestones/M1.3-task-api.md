# M1.3: Task API

Phase: [P1](../phases/P1.md)

## Goal
Manual tasks work end to end: idempotent create, edit, lifecycle with events, delete with cascade, the days endpoint with workload, and move-unfinished.

## Acceptance criteria
- [ ] Concurrent `POST /tasks` with the same id yields one row
- [ ] Events contain only allowlisted fields
- [ ] Workload and carry-over use the logical day

## Demo when done
Use curl to create, complete, reschedule and delete tasks, and show `GET /days/{date}` with workload.
