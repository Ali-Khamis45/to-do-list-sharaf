## Goal
Write the sqlc queries and store functions for conversations, messages with revisions, transcriptions, analysis runs with reason codes, and proposal items with revisions and statuses.
This includes the conversation lock and the production dedupe candidate query.

## Tasks
- [ ] Query files `db/queries/{conversations,messages,transcriptions,analysis,proposals}.sql` and matching `internal/store/*.go`
- [ ] Conversation row lock (`SELECT … FOR UPDATE`), plus insert-on-conflict for `clientMessageId` and `uploadId`
- [ ] Fetch items by source messages in every status, for the re-proposal guard
- [ ] Dedupe candidates: the user's open tasks within ±1 day, Later tasks, and pending items, scored by the S0.10 Scorer
- [ ] Every query is scoped by `user_id`
