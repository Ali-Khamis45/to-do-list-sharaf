## Goal
Two seeded accounts log in with passwords (scs and bcrypt). Add `/me` and the settings endpoints.
Add `DELETE /me/data`, which deletes all of a user's data but keeps the account.

## Read first
- [data-and-api.md](../../data-and-api.md) §8 (users, sessions), §9 (auth and me endpoints)
- [product-requirements.md](../../product-requirements.md) §3 (accounts)
- [architecture-and-ai-pipeline.md](../../architecture-and-ai-pipeline.md) §11 (session cookie)

## Tasks
- [ ] Add a seed command that creates the 2 users from the `SEED_*` env values
- [ ] Login and logout with the scs Postgres store. Cookies are HttpOnly, Secure and SameSite=Lax.
- [ ] `GET /me` and `PATCH /me/settings`, validating the IANA timezone, day boundary, `task_language` (spoken|en|ar), capacity and retention
- [ ] `DELETE /me/data` deletes conversations, tasks and transcriptions in one transaction
- [ ] Add a user-scoping helper used by every handler
