## Goal
Capture at least 10 genuine nightly brain-dumps, 5 each, before any prompt exists.
They become the held-out split, which the prompt author never reads.

- [roadmap-and-testing.md](../../roadmap-and-testing.md) §12.2 (held-out split rules)

## Tasks
- [ ] On real nights, record yourself talking about your day and tomorrow for 1–3 minutes on your phone's voice recorder
- [ ] Save the audio as `eval/clips/heldout/<speaker>-<yyyymmdd>.<ext>`
- [ ] Write an exact reference transcript next to it (`.txt`, same name). Write it as spoken, with English terms in Latin script.
- [ ] Write a `.meta.txt` with the local date and time of recording and a rough list of the tasks you already had that day
- [ ] Skip any night you'd rather keep private and record another one
- [ ] Never paste these into a Claude Code session

## Files/dirs this sprint may touch
Touch nothing else. If you need another file, stop and write the request in the handoff notes. See the ownership table in [README.md](../README.md#file-ownership).

## Acceptance criteria
- [ ] At least 10 nights in total, with at least 4 per speaker
- [ ] Each night has audio (or a note saying text only), a `.txt` and a `.meta.txt`
- [ ] All recorded before S0.11 starts
