## Tasks
- [ ] Pick the LLM vendor for the single adapter. Paste 2 **dev** scenario texts (never real nights) into each candidate's playground and compare the answers.
- [ ] Create API accounts: OpenAI (STT), Groq, ElevenLabs, optionally Google, plus the chosen LLM vendor
- [ ] Read each provider's API data-use terms (no training on API data) and note the result in the handoff
- [ ] Set a monthly spend alert or hard cap on each account
- [ ] Put the keys in a local `.env` using these names: `LLM_API_KEY`, `LLM_MODEL`, `STT_OPENAI_API_KEY`, `STT_GROQ_API_KEY`, `STT_ELEVENLABS_API_KEY`, `STT_GOOGLE_CREDENTIALS` (optional). Never commit `.env`.
